# Risk Memory — 주행 순간 복기

Pleos Connect에서 조작할 수 있는 오프라인 Android 시제품입니다. 기존 HutgeoreumZero 프로젝트와 패키지를 보존하고 별도 프로젝트/앱 `com.riskmemory.map`으로 만들었습니다.

## 사용법

1. `시험 주행 시작`을 누르면 64초 시험 데이터를 2배속(약 32초)으로 재생합니다.
2. 급감속 후보 2건, 급조향 후보 1건이 나타납니다. 데이터 값에 실제로 탐지 로직을 적용합니다.
3. 종료하면 경로 도식, 요약, 필터 가능한 타임라인을 봅니다. 각 기록/지도 표시를 눌러 상황 메모를 남깁니다.
4. `같은 경로 재주행` 후 다시 시작하면 이전 기록 구간 직전에 알림이 나타납니다. 동일 지점·종류를 중복 안내하지 않고 최소 8초 간격을 둡니다.
5. 기록은 기기 내에 최대 12개 보관합니다. 기록 삭제는 확인 후 진행합니다. 앱 전환/회전 시 시험 재생은 멈추고 이어서 재생할 수 있습니다.

## 구현 경계

- 모든 주행 데이터는 시험 데이터이며 Vehicle SDK/실차 센서에 연결하지 않았습니다.
- 경로 도식은 실제 도로 지도나 GPS 위치가 아닙니다. 재방문은 같은 방향의 단일 시연 경로에서 진행 시점을 비교합니다.
- 미끄러짐, 사고, 과실, 검증된 위험도/안전 점수를 판정하지 않습니다.
- 클라우드·익명 공유·타인 데이터·내비게이션 경로 안내는 없습니다.
- 인터넷·위치·마이크 권한을 요청하지 않습니다. 한국어 TTS가 있으면 선택적으로 시연 알림을 읽습니다.

## 탐지와 테스트

가속도 `(속도차/3.6)/시간차`가 -3 m/s² 이하이면 급감속 후보(이전 속도 15 km/h 이상), 조향각 변화율 70°/s 이상이며 전후 속도가 30 km/h 이상이면 급조향 후보로 기록합니다. 같은 종류의 중복은 8초 동안 억제합니다. 2.5초 초과 공백, 역순·중복 시각, 비정상 수치는 제외합니다. 수치는 검증된 안전 기준이 아닙니다.

`tests/DriveEngineTest.java`: 시연 결과 순서, 임계값, 중복 억제, 저속 조향 제외, NaN/null, 시각 역전 및 공백 처리를 검사합니다.

## 빌드

JDK 17 / Gradle 8.9 / AGP 8.7.3 / Android SDK 35 / minSdk 28. `powershell -NoProfile -ExecutionPolicy Bypass -File .\build-risk.ps1`로 테스트·컴파일·APK 패키징을 합니다. 처음 필요한 의존성이 없으면 `-Online`을 추가합니다.

이 환경에서는 javac의 Windows JAR canonical-path 처리에 AccessDeniedException이 있어 `tools/CompileAndroid.java`가 읽기 가능한 실제 SDK 클래스 바이트를 메모리에 제공하고 JavaCompiler로 소스를 컴파일합니다. 이 단계가 성공한 후에만 Gradle에서 중복 JavaCompile 단계를 제외하여 패키징합니다. SDK 파일이나 시스템 권한을 변경하지 않습니다.

보조 빌드 스크립트는 개발용 서명 키를 `.gradle/risk-debug.keystore`에 복사해 사용하며 저장소 제외 대상입니다. Android Studio의 일반 빌드는 기본 디버그 서명을 사용합니다. 릴리스용 서명이나 배포는 하지 않습니다.
실행 중인 Pleos에서 앱을 다시 열려면 RUN-RISK.cmd를 더블클릭합니다. 검증 내역은 VERIFICATION.txt를 참조하세요.
